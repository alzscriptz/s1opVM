# s1opVM

## s1op Installer website

A static experimental landing page / setup UI is in `website/`. Deploy with Vercel using `website` as the Root Directory.

**Important:** The current website is a UI prototype. Browsers cannot reliably detect LocalDevVPN, enter iOS Developer Mode, pair a real iPhone, sign an IPA, or install it. The visible check is deliberately a non-invasive demo state. Do not collect Apple ID credentials or verification codes in this web app.
